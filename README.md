# 火宝（fire）使用说明

火宝是一款 Windows 桌面软件，可以使用自己的抖音账号，向指定好友发送文字、Emoji 和图片，并设置每天自动发送的时间。

日常使用通过界面操作，不需要打开终端。当前支持一个登录账号，最多添加 20 位好友。

**普通用户推荐下载安装版：无需安装 Python、Playwright、浏览器或其他运行环境。**

## 1. 下载、安装和启动

### 方式一：Windows 安装版（推荐）

支持 Windows 10 / 11 64 位。

1. 打开本项目 GitHub 页面，进入右侧 **Releases**。
2. 在最新版本的 **Assets** 中下载 `HuoBao-Setup-1.0.0-win-x64.exe`（后续版本文件名中的版本号会变化）。
3. 双击安装文件，按向导完成安装，可选择创建桌面快捷方式。
4. 在桌面或开始菜单打开 **火宝**。
5. 点击扫码登录，开始设置好友和发送内容。

安装版已内置 Python、依赖、界面资源和 Chromium。第一次启动不需要安装或下载运行环境，但登录抖音和发送消息需要联网。

**不要把 GitHub 的“Code → Download ZIP”或 Release 自动生成的“Source code”当作安装包。** 这两项是源码。

默认安装位置：`%LOCALAPPDATA%\Programs\HuoBao`。不需要管理员权限。

### 方式二：源码版（开发者或已有 Python 的用户）

1. 安装 Python 3.10 或更高版本，安装时勾选 **Add Python to PATH**。
2. 下载并解压整个项目。
3. 双击 **启动fire.vbs**。
4. 如出现环境安装窗口，保持联网并等待完成。
5. 进入软件登录页。

源码版优先使用 Microsoft Edge；没有 Edge 时会尝试下载 Chromium。也可双击 `start.pyw`，前提是 Python 文件关联正确。请保留整个文件夹及 `assets`，不要只移动启动文件。

两种版本均只允许同时运行一个实例；切换版本前请从托盘菜单退出旧实例。

## 关闭窗口与后台运行

点击右上角 **×** 会隐藏窗口，软件留在电脑右下角系统托盘，继续执行已开启的每日计划和当前任务，不会退出。

- 点击托盘火苗图标，或右键选择 **打开火宝**，可以恢复窗口。
- 若图标没有直接显示，点击任务栏右下角的 **˄** 查看隐藏图标。
- 需要真正关闭软件时，右键托盘火苗，选择 **退出软件**。有任务或计划运行时会询问是否退出。
- 托盘隐藏不等于开机自启。电脑关机、休眠或断网时不能执行发送；重启后仍需手动打开软件并开启计划。

## 2. 登录抖音账号

### 第一次登录或切换账号

1. 点击 **扫码登录 / 切换账号**。
2. 在弹出的抖音浏览器窗口中，使用手机抖音扫码。
3. 如果抖音要求短信验证或其他验证，请在窗口内完成。
4. 软件识别登录成功后，会保存登录状态并进入设置页。

二维码过期时，可在抖音窗口刷新二维码。扫码等待最长约四分钟，超时后可以重新操作。

### 登录已保存账号

1. 点击 **登录已保存账号**。
2. 软件立即进入设置页，在后台验证账号，不弹出浏览器。
3. 验证期间可以编辑好友和发送内容；**立即发送**会暂时禁用。
4. 显示 **已登录** 后，即可发送或开启每日计划。

如果验证失败，可点击 **重新验证**。登录过期或需要安全验证时，点击 **切换账号**，再选择扫码登录。

左上角显示账号头像和名称。头像会缓存到本机；昵称读取不到时，软件可能要求填写一个本机显示名称。

## 3. 添加并选择好友

在第二页左侧操作：

1. 在输入框填写好友的**完整昵称或备注**。
2. 点击 **添加好友**，也可以在输入框按回车添加。
3. 勾选好友前面的小方块，表示本轮需要给该好友发送。
4. 取消勾选后，该好友仍留在列表中，但不会参与发送。
5. 点击好友右侧的 **×**，可以从列表中移除。

- 最多添加 **20 位**好友，重复名称不能再次添加。
- 列表支持滚动查看。
- 只发送给已勾选的好友。
- 好友列表和勾选状态会即时保存。
- 如果好友重名，请先在抖音设置唯一备注，再使用该备注添加。
- 添加好友只是设置发送目标，不会向抖音发出好友申请。

首次使用建议只勾选一位测试好友。

## 4. 设置发送内容

### 发送文字和 Emoji

在右侧单行文字栏填写内容。

点击下方的火苗、爱心、笑脸、玫瑰、点赞按钮，可以插入彩色表情。界面使用彩色图案展示，保存和发送时会转换为对应的 Emoji。

### 发送图片或表情包

1. 点击 **选择表情包图片**。
2. 选择 PNG、JPG、JPEG、GIF 或 WebP 文件。
3. 在预览区确认图片。
4. 如果需要更换，重新选择即可；预览区只保留一张图片。
5. 不想发送图片时，点击 **清除图片**。

GIF 在预览区显示第一帧，原 GIF 文件用于上传。WebP 发送前会转换为 PNG，因此 WebP 动画不会保留为动画。

这里发送的是本机图片文件，不是抖音收藏表情中的原生表情。

### 内容组合

| 填写内容 | 发送行为 |
| --- | --- |
| 只有文字或 Emoji | 发送一条文字消息 |
| 只有图片 | 发送一张图片 |
| 文字和图片都有 | 先发送文字，再发送图片 |
| 两者都为空 | 无法发送，界面提示补充内容 |

文字与图片是两次独立发送，可能出现文字成功、图片失败的情况。当前所有勾选好友共用同一份发送内容。

## 5. 立即发送

1. 等待账号显示 **已登录**。
2. 勾选需要发送的好友。
3. 检查文字和图片。
4. 点击 **立即发送**。

软件会保存当前设置，在后台依次处理好友，发送时不弹出浏览器。

**每点击一次都会执行一轮。立即发送不使用每日计划的防重复记录，重复点击可能再次发送。**

发送过程中，请查看下方运行记录。若遇到失败或无法确认的状态，本轮会停止，剩余好友不会继续执行，也不会自动重发。

## 6. 设置每天自动发送

1. 点击 **发送时间设定**。
2. 填写每天的发送时间，格式为 `HH:MM`，例如 `09:00` 或 `18:30`。
3. 填写不同好友之间的发送间隔，单位为秒。
4. 勾选 **开启每日自动发送**。
5. 点击 **保存时间设置**。

时间统一使用**北京时间**。开启计划前，账号必须通过验证，并且至少选择一位好友、设置一项发送内容。

### 计划运行规则

- 必须保持软件开启、电脑唤醒并联网。
- 通过托盘菜单退出软件会停止计划，重新打开后需要主动开启；点击窗口 × 隐藏到托盘不停止计划。
- 错过的时间不会补发。
- 如果开启计划时恰好处于设定分钟，可能立即执行。
- 同一天、同一个时间点只自动尝试一次；即使失败，也不会自动重发。
- 软件正在执行其他任务时，计划不会并行运行；如果因此错过设定分钟，不会补发。
- 好友间隔会影响整轮耗时，例如间隔设为 10 秒，处理下一位好友前就会等待 10 秒。

### 暂停每日计划

打开 **发送时间设定**，取消勾选 **开启每日自动发送**，再保存。

修改时间或内容后，也请点击保存。底部文字会显示当前计划时间及是否开启。

## 7. 查看进度和结果

### 动图进度条

- 已保存账号验证时，进度按读取记录、启动浏览器、加载页面、核验账号、更新资料等阶段推进。
- 发送时，进度按本轮已处理的好友数推进。
- **100% 表示本轮目标已处理完，不等于所有消息都成功。**
- 失败时会显示停止状态，并保留当前进度。
- 动图在 0% 和 100% 时也会持续播放；动画播放不代表仍在发送。

### 运行记录

| 状态 | 含义 |
| --- | --- |
| 发送成功（页面确认） | 检测到新发出的本人消息，并观察到发送中状态消失、没有失败标记 |
| 失败 | 定位、上传或发送过程中出现明确错误 |
| 发送状态未确认 | 已操作，但无法可靠确认结果；可能已经发出，需要在抖音查看 |
| 剩余好友未执行 | 本轮因异常停止，这些好友还没有处理 |

“发送成功”不代表好友已经阅读。**遇到状态未确认时，先在抖音核对聊天记录，再决定是否重发。**

失败时，`artifacts` 文件夹会保存截图和同名 JSON 错误记录。JSON 中包含失败阶段和具体原因；截图可能含私密聊天，不要公开分享。

## 8. 常见问题

### 双击没有打开软件

安装版：请从桌面或开始菜单打开火宝；如果正在后台运行，点击右下角托盘火苗。安装版不要求 Python。

源码版：

- 确认 Python 已安装，并已添加到 PATH。
- 尝试双击 `start.pyw`。
- 检查是否已有一个火宝窗口正在运行。
- 首次安装失败时，查看项目文件夹里的 `setup.log`，保持联网后重试。

### 已保存账号验证很慢

软件进入设置页后仍需等待抖音聊天页响应，期间可以先编辑设置。首次加载可能较慢；验证完成后，保持软件开启，后续验证和发送会复用后台浏览器与已加载页面。

如果长时间没有完成，可尝试 **重新验证**；提示登录过期时重新扫码。

### 立即发送按钮不能点击

账号还未通过后台验证。等待显示 **已登录**，或按界面提示重新验证、扫码。

### 搜索不到好友

确认填写的是抖音中的完整昵称或备注，并先在抖音网页版确认能搜索到。重名时请设置唯一备注。

### 图片显示在预览区，但发送失败

预览只说明本机能读取文件，不代表抖音已接受上传。查看运行记录中是 **上传图片** 还是 **发送图片** 阶段失败，再检查 `artifacts` 中对应的错误记录。

如果显示状态未确认，先检查抖音聊天记录，避免重复发送。

### 到时间没有自动发送

依次确认：

1. 账号显示已登录。
2. 每日自动发送已开启并保存。
3. 好友已勾选，发送内容不为空。
4. 时间使用北京时间。
5. 软件仍在运行（窗口打开或托盘后台均可），电脑没有休眠或断网。
6. 当时没有其他任务占用软件。
7. 当天该时间点没有已经触发过。

### 怎么保存设置

好友添加、删除和勾选会即时保存。文字、图片及时间设置会在保存时间设置或点击立即发送时保存；只编辑文字后直接退出，内容可能没有保存。

### 是否保证火花不断

软件自动完成的是本人一侧的消息发送。火花是否维持仍取决于抖音规则、双方互动和实际发送结果。

## 9. 本机数据与更新

安装版的账号、Cookie、好友设置、头像和错误截图保存在：

```text
%LOCALAPPDATA%\HuoBao
```

可以把这个路径粘贴到文件资源管理器地址栏打开。安装目录里只有程序和公开资源，发布的安装包不含作者的登录记录。首次使用安装版需要自己扫码。

更新时，先在托盘退出火宝，再下载安装新版本；同一路径下的本机数据会保留。卸载程序默认也保留用户数据。如需清除账号和设置，退出软件后自行删除上述用户数据文件夹。

源码版的数据保存在项目文件夹中，文件用途如下：

### 文件说明

| 文件或目录 | 用途 |
| --- | --- |
| `启动fire.vbs` | 日常双击启动入口 |
| `start.pyw` | 环境准备和无终端启动 |
| `desktop.json` | 好友、内容、图片路径及时间设置 |
| `auth/` | 登录状态、Cookie、头像和计划触发记录 |
| `assets/` | 界面图片、表情图标和进度动图 |
| `artifacts/` | 失败截图与错误记录 |
| `setup.log` | 首次依赖安装日志 |

`auth` 文件夹包含账号登录凭证，**不要发给别人，也不要上传到公开仓库**。更换电脑后建议重新扫码登录。

## 10. 在 VS Code 中打开项目（可选）

日常使用不需要 VS Code。如果需要修改程序：

1. 使用 VS Code 打开整个 `fire` 文件夹。
2. 安装推荐的 Python 与 Python Debugger 扩展。
3. 选择本机 Python 3.10+ 解释器。
4. 在“运行和调试”中选择 **fire 桌面界面**，点击运行按钮或按 F5。

已安装运行环境时，也可以选择 **fire GUI 调试（环境已安装）**。

## 11. 构建和发布安装包（维护者）

普通用户无需执行本节。

1. 在 Windows 64 位电脑安装 Python 3.10+ 和 Inno Setup 6。
2. 在项目文件夹运行 `powershell -ExecutionPolicy Bypass -File build_windows.ps1`。可用 `-Version 1.0.1` 指定版本，用 `-Iscc 路径` 指定 Inno Setup 编译器。
3. 脚本安装构建依赖、下载 Chromium，再用 PyInstaller 打包并生成安装程序。
4. 成品位于 `releases/HuoBao-Setup-版本号-win-x64.exe`。
5. 在 GitHub 创建 Release，上传安装 EXE 和 SHA256 校验文件，填写版本说明。

`dist/`、`build/`、`work/`、`releases/` 和生成的 `*.spec` 不提交到源码仓库。安装 EXE 放在 GitHub **Releases**，不要直接拖进仓库文件列表。打包脚本只收录代码、公开 assets、示例配置和浏览器，不收录 auth、个人设置或 artifacts。
