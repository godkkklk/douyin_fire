# douyin_fire
火宝（fire）是一款面向 Windows 用户的抖音好友互动助手，采用 Python、Playwright 和图形界面开发，支持扫码登录、保存登录状态及后台验证。用户可添加最多20位好友，通过勾选选择发送对象，设置文字、彩色 Emoji 或单张图片，并使用立即发送或每日定时发送功能。软件支持图片预览、好友发送间隔设置、发送结果记录和动图进度展示；关闭窗口后可驻留系统托盘，继续执行已开启的任务。安装版内置运行环境和浏览器，无需额外安装 Python 或配置依赖。账号凭证与个人设置保存在本机，发布包不包含开发者的 Cookie。软件会核对好友身份和页面发送状态，遇到异常时停止任务并保存诊断信息，减少误发及重复发送。自动任务需要电脑保持唤醒、联网且软件持续运行。
